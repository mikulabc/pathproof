# Support

- Use [GitHub Discussions](https://github.com/mikulabc/pathproof/discussions) for setup help, usage questions, and ideas.
- Use [GitHub Issues](https://github.com/mikulabc/pathproof/issues) for reproducible bugs and scoped feature requests.
- Use private vulnerability reporting for security concerns.

Include your operating system, Node.js version, Pathproof version, reproduction steps, and sanitized logs. Never share API keys, cookies, recordings, customer URLs, or `.data/` contents.
